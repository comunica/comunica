# QT3 test files

These files are taken unchanged from the [W3C XQuery and XPath Test Suite (QT3)](https://github.com/w3c/qt3tests),
at commit [`201a6e466940cdfc727f4babfedcde5332b9f578`](https://github.com/w3c/qt3tests/tree/201a6e466940cdfc727f4babfedcde5332b9f578).
They are the catalog and the test sets for the functions and operators that SPARQL defines in terms of XPath,
which `../../XPathTestSuite-test.ts` runs against the expression engine.

They can be fetched again with `yarn run fetch-qt3` in `engines/expressions-sparql`.
